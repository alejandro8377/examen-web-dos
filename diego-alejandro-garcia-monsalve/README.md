## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Instalación y ejecución

```sh
npm install
npm run dev
```

Para validar la compilación y el lint:

```sh
npm run build
npm run lint
```

## Vistas

- `/`: resumen y publicaciones destacadas.
- `/catalogo`: búsqueda por texto y filtro por categoría.
- `/contacto`: canales de atención y formulario controlado campo por campo.

El mock de publicaciones está en `src/data/libros.js`. Las páginas, componentes, rutas y estilos están separados en sus carpetas dentro de `src/`.
